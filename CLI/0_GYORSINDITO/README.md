# 0_GYORSINDITO

Egy **leforduló, futtatható** projekt. A `Program.cs`-ben minden gyakori feladattípus egy jelölt blokk, és fölötte az áll, hogy milyen feladatszövegnél kell.

| Blokk | Mire jó |
|---|---|
| [A] | beolvasás listába |
| [B] | megszámolás (`Count`) |
| [C] | összeg, átlag |
| [D] | legnagyobb / legkisebb elem |
| [E] | holtverseny (mindegyik legnagyobb) |
| [F] | szűrés és kiírás |
| [G] | rendezés, top 3 |
| [H] | csoportosítás („…-nként”) |
| [I] | hány különböző (`Distinct`) |
| [J] | van-e / mindegyik (`Any`, `All`) |
| [K] | bekérés + keresés + „Nincs ilyen” |
| [L] | fájlba írás |
| [M] | Dictionary-s számlálás |
| [N] | dátumok |
| [O] | kerekítés, metódus az osztályban |

## Használat a vizsgán

1. Az `Elem.cs` tartalmát másold a saját osztályodba, nevezd át (pl. `Auto`), és írd át a mezőket a fejléc szerint.
2. A `Program.cs`-ből csak a kellő blokkokat másold, és írd át a mezőneveket, a szövegeket és a feladatszámot (`5. feladat:`).
3. A fájlnevet (`adatok.csv`) írd át a sajátodra.

Futtatva ezt írja ki (bekért név: `sajt`):

```
[A] Beolvasott sorok: 13
[B] Aktív gyümölcsök: 4 db
[C] Összeg: 9860,20, átlag: 758,48, gyümölcsátlag: 869,18
...
```
